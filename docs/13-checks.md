

# Лабораторная работа №13 — NewsPortal



## Цель работы



Реализовать работу с базой данных через Repository,

CRUD-операции, поиск, фильтрацию, пагинацию

и серверную валидацию.



## Реализованные компоненты



1. NewsRepository — работа с новостями.

2. CategoryRepository — работа с категориями.

3. UserRepository — работа с пользователями.

4. NewsValidator — серверная проверка данных.

5. NewsController — обработка HTTP-запросов.
